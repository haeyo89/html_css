1. A-3: 다크/라이트 모드 테마 전환 (CSS 전용)
자바스크립트 없이 체크박스의 상태(:checked)를 활용하는 것이 핵심입니다.

HTML 구조:

<input type="checkbox" id="theme-toggle">: 화면에는 숨겨두고 ON/OFF 상태만 저장하는 스위치 역할.

<label for="theme-toggle">: 클릭 시 체크박스를 클릭한 것과 동일하게 작동하는 진짜 스위치 버튼.

CSS 핵심 문법:

box-sizing: border-box;: 여백(padding) 때문에 박스 크기가 커지지 않게 크기를 고정.

transition: background-color 0.4s ease;: 색상이 바뀔 때 0.4초 동안 부드럽게 애니메이션 처리.

#theme-toggle:checked ~ .page-container: (가장 중요) 체크박스가 체크되면 형제 요소인 .page-container 전체 배경을 #222(어두운 회색)로 변경.

transform: translateX(34px): 다크 모드 ON 시 스위치 안의 동그라미 핸들을 오른쪽으로 34px 이동.

2. A-4: 회원가입 폼
시맨틱 태그와 입력 폼의 필수 속성 및 마우스 효과를 다루는 것이 핵심입니다.

HTML 구조:

<form>과 <input>: 사용자 입력을 받는 기본 틀.

required 속성: 입력 필드에 required를 넣어두면 값이 비어 있을 때 브라우저가 제출을 막고 경고창을 띄움.

<span class="required-mark">*</span>: 필수 입력 항목임을 사용자가 한눈에 알 수 있도록 빨간색 별표 표시.

CSS 핵심 문법:

.form-group: 입력 필드(label + input) 단위로 감싸서 아래쪽 여백(margin-bottom)을 일정하게 유지.

input:focus: 사용자가 입력창을 클릭했을 때 테두리 색상을 파란색으로 바꿔서 강조.

.submit-btn:hover: 버튼 위에 마우스를 올렸을 때(:hover) 버튼 배경색을 어두운 파란색으로 변경하여 클릭 반응 제공.
